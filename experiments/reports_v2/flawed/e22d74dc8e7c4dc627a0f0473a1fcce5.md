Both descriptions use the same verbs (undo, reverse) and neither says which order status it applies to. After the error, nothing in the tool text told the model that `cancel_order` covers orders that have not shipped. This contributes to finding 1. One trace is weak evidence of overlap, hence medium.

The "shipped or delivered" rule is the model's inference, presented as store policy. It may be right, but the trace does not show it. `get_store_policy` (topic `returns`) was the tool to use. Confidence is medium because the claim is a plausible reading of the error.

## Suggested fix

fix_location: error_message, tool_description
Location: server behaviour of `start_return` (error text), plus the descriptions of `start_return` and `cancel_order`

Why here: the rule "returns need a shipped order, unshipped orders are cancelled" belongs to these two tools, so it goes in the tool error and descriptions and not in the system prompt.

```diff
# start_return, error returned by the server
- Order BK-10571 is not eligible for return because its status is processing.
+ Order BK-10571 is not eligible for return because its status is processing (not yet shipped). Returns are only available after an order has shipped. To stop this order, use cancel_order.
```

```diff
# cancel_order, description
- Undo an order. Use this when the customer wants to reverse or back out of an order they placed.
+ Cancel an order that has not shipped yet (status processing). Use this when the customer wants to back out before it ships. Do not use for shipped or delivered orders; use start_return.

# start_return, description
- Reverse an order. Use this when the customer wants to undo a purchase and get their money back.
+ Start a return for an order that has already shipped or been delivered, to get money back. Do not use for orders still processing; use cancel_order.
```

Assumption: the eligibility rules (return only after shipping, cancel only before shipping) are inferred from the error text and the tool names. Check them against the real server rules before applying the wording.
