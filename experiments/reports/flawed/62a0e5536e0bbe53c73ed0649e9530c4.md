## Suggested fix

Location: tool description of `get_store_policy`

Why here: the rule "look up the store's rules before describing options" belongs to the policy tool, and its current wording excludes the order-specific situation where it is needed; it is not a cross-tool prompt issue.

```diff
- Return the official store policy text for one topic: returns, shipping or cancellations. Use it for questions about how the store's rules work rather than about a specific order.
+ Return the official store policy text for one topic: returns, shipping or cancellations. Use it for questions about how the store's rules work, and also when an order action is refused (for example cancelling a shipped order) and you need to tell the customer what options exist. Do not describe store rules or alternatives that did not come from this tool.
```

Optional, server side: have `cancel_order` return the next step in its error (for example, a pointer to the returns policy) once the store confirms what that step is. I have not guessed the policy here.
