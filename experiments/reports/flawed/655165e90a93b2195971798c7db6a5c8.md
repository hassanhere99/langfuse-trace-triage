### 2. Misleading final answer (note, not a catalog failure type; confidence: medium)

Evidence:

> "I couldn't find any information on a book called "Dune" by Frank Herbert that is specifically recommended for a 14-year-old. However, I can tell you that "Dune" is a classic science fiction novel written by Frank Herbert, published in 1965."

The empty search result is about the catalog, but the answer describes it as missing information about the book, then supplies facts from memory (published 1965, mature themes). It is not `missing_tool_call`, because no available tool could supply age-suitability information. It is also not `tool_error_mishandled`: the result was empty, not an error.

## Suggested fix

Location: tool description of `search_books`

Why here: the rule "use this for catalog lookups, not for questions about book content" belongs to this one tool, so it goes in its description and not in the system prompt.

```diff
- Search the bookstore catalog by title, author or ISBN. Returns up to five matching books with ISBN, title, author, price in USD and the number of copies in stock.
+ Search the bookstore catalog by title, author or ISBN. Returns up to five matching books with ISBN, title, author, price in USD and the number of copies in stock. Use it when the customer asks whether we sell a book, its price, or whether it is in stock. It has no reviews, age ratings or plot information, so do not use it for questions about a book's content or suitability for a reader.
```

A 3B model may not follow this reliably. Check it with the test below.
